
# Beekeeper — додаток для обліку бджолородин

Веб-додаток (PWA) для Android з голосовим керуванням на основі AI. Українська мова інтерфейсу та голосових команд.

## Технології

- TanStack Start (React) + Tailwind + shadcn/ui
- Lovable Cloud (база даних, авторизація, файли)
- Lovable AI Gateway — Gemini для розуміння голосових команд
- Web Speech API — розпізнавання мови (українська) у браузері
- PWA-маніфест — встановлення на головний екран Android

## Авторизація

- Email/пароль + Google вхід
- Таблиця `profiles` (ім'я, аватар) пов'язана з `auth.users`
- Усі дані ізольовані по `user_id` через RLS

## Структура головного меню

1. **Моя пасіка** — назва, адреса/локація, опис, фото
2. **Мої вулики** — список бджолородин з картками
3. **Календар виведення маток** — графік з нагадуваннями (запліднення, вихід, перевірка)
4. **Календар пасічника** — сезонні роботи (весна/літо/осінь/зима)
5. **Купи / Продай** — оголошення (бджолопакети, матки, мед, інвентар)
6. **Чат з бджолярами** — спільнота, повідомлення в реальному часі

## Дані по вулику (бджолосім'ї)

- Номер вулика, дата заселення
- Порода, рік народження матки, мічення
- Сила сім'ї (кількість рамок з бджолою/розплодом)
- Журнал оглядів (дата, замітки, голосові нотатки)
- Годування (сироп/канді, дата, кількість)
- Обробки (від вароа тощо — препарат, доза, дата)
- Збір меду (дата, кг)
- Стан зимівлі, фото

## Голосове керування

Плаваюча кнопка мікрофона на всіх екранах. Сценарій:

1. Користувач натискає мікрофон → Web Speech API записує українською
2. Розпізнаний текст → Lovable AI (Gemini) з системним промптом, який витягує структуровану дію:
   - `{ action: "add_inspection", hive: 5, notes: "матка червить, додав рамку" }`
   - `{ action: "open", screen: "calendar" }`
   - `{ action: "add_feeding", hive: 3, amount: "1 л сиропу" }`
3. Підтвердження на екрані → запис у БД

Приклади команд:
- «У вулику 5 додав рамку, матка червить добре»
- «Відкрий календар маток»
- «Записати обробку від вароа у вуликах 1-10»

## Календарі та нагадування

- Виведення маток: автоматичний розрахунок дат (запечатування, вихід, обліт, перевірка засіву) від дати щеплення
- Календар пасічника: типові роботи за місяцями, можна редагувати

## База даних (Lovable Cloud)

`profiles`, `apiaries`, `hives`, `inspections`, `feedings`, `treatments`, `harvests`, `queen_rearing_batches`, `calendar_events`, `marketplace_listings`, `chat_messages`. Усі з RLS по `user_id` + grants для `authenticated`.

## PWA

- `manifest.webmanifest` (ім'я, іконки, theme color, `display: standalone`)
- Іконки 192/512, apple-touch-icon
- Без service worker (без офлайн-режиму на старті — можна додати пізніше)

## Етапи розробки

1. Підключити Lovable Cloud, авторизацію (email + Google), створити profiles
2. Головне меню (6 розділів) + PWA-маніфест + іконки
3. «Моя пасіка» + «Мої вулики» (CRUD, картки, огляди)
4. Голосова кнопка + інтеграція з AI для парсингу команд
5. Календар виведення маток (з автоматичним розрахунком дат)
6. Календар пасічника
7. Купи/Продай (оголошення з фото)
8. Чат бджолярів (realtime)

Почнемо з кроків 1–3, далі ітеративно додамо решту.
