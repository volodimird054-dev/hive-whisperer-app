# Уточнення технічних карт виведення маток

## Що зміниться
- У першому етапі способу «Сот» замінити пораду на: «Обмежте матку в пластиковому соті у сильній материнській сім’ї.»
- У фінальному етапі підсаджування для обох способів залишити точний текст: «Підсаджуйте неплідних маток у відводки протягом перших трьох днів після виходу.»
- Зробити кнопку «Нова партія» звичайною горизонтальною кнопкою.
- Замінити тавтологічний підпис про майбутній вибір на короткий зрозумілий текст.
- Після завершення всіх етапів зберігати дату завершення; через 7 днів автоматично переміщувати партію з активного списку до архіву.
- Додати архівовані партії до розділу архіву з можливістю відновлення або остаточного видалення.

## Технічні деталі
- При відмітці етапу зберігати `done_on`; при скасуванні відмітки очищати її.
- Активний список виключає `archived_at`; під час завантаження прострочені завершені партії отримують `archived_at`.
- Для старих завершених партій без дати останнього етапу використовувати дату останнього оновлення партії, якщо таке поле доступне.
